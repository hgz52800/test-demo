# 海心 AI GEO 工作台重构实施计划

> 按可预览的增量交付；每个阶段只改变一个视觉/交互责任面，保持现有业务服务与领域模型。

## 1. 全局设计系统与应用框架

- 更新 CSS 变量为冰川白、深海蓝、靛蓝、冷灰和弱边界层级。
- 重做 232px 桌面侧栏、折叠图标栏、九个主入口、“更多工具”分组、移动抽屉与顶部操作区。
- 添加导航折叠、当前路由高亮、抽屉关闭与焦点返回；保留搜索、通知、帮助、账户现有反馈。
- 核对桌面、平板、手机断点以及减少动效偏好。

## 2. GEO 总驾驶舱

- 保留 DashboardService、OpportunityService、DateRange 和现有操作状态。
- 将 GEO 综合指数做成主指标，将曝光、推荐、引用、问题覆盖、竞品差距压缩成相邻指标。
- 图表与平台表现左右并列；用真实演示样本扩展机会列表到七项并呈现平台、问题、影响、竞品表现及原有详情入口。
- 新增基于现有机会证据的可观测差距诊断摘要，避免声称了解模型内部原因。
- 保留日期筛选、错误/加载/空状态、详情抽屉、生成方案和建任务流程。

## 3. 模块与组件统一

- 以共同标题、分段导航、状态胶囊、紧凑摘要和折叠/抽屉交互重制模块预览页。
- 修复长文本、图表容器、表格摘要和窄屏布局；保持所有原有导航路径可达。
- 为按钮悬停、面板进入、数字轻微更新和消息提示统一短时过渡。

## 4. 验证与发布

- 运行现有类型检查与静态构建。
- 在实际浏览器检查 1440px 与 390px，覆盖桌面导航折叠、移动抽屉、总览和至少一个模块页；检查控制台和横向溢出。
- 使用站点托管工作流保存修改后的源码与静态产物，并发布到既有私有站点，沿用既有访问范围。
